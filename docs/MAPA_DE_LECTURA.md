# Mapa de Lectura — SUBE Prioridad

## Guía de recorridos documentales según perfil de lector

---

## 1. Finalidad de este documento

Este documento orienta la lectura del repositorio SUBE Prioridad según el perfil, interés o necesidad de cada persona lectora.

No reemplaza al README ni al Índice Documental.

Su función es ayudar a responder preguntas como:

```text
soy ciudadano, qué leo primero
soy legislador, qué documentos necesito revisar
soy autoridad pública, por dónde empiezo
soy técnico, qué archivos debo mirar
soy abogado, qué fundamentos son relevantes
soy especialista en datos, qué documentos importan
soy periodista, cómo comunico el proyecto sin confundirlo
soy posible custodio institucional, qué debo revisar antes de avanzar
```

SUBE Prioridad debe interpretarse como una iniciativa ciudadana abierta, conceptual, demostrativa y documentada, impulsada originalmente por Andrés Federico Di Fiore, orientada al análisis de accesibilidad efectiva, asistencia preventiva y convivencia dentro del transporte público.

El proyecto no representa una implementación oficial vigente, una integración productiva con SUBE, una conexión real con organismos públicos, una modificación actual de validadoras, una base de datos médica ni un sistema de sanciones.

## 21. Cierre

Este Mapa de Lectura organiza los recorridos documentales según el perfil de cada lector.

El proyecto debe leerse siempre como una propuesta ciudadana abierta, prudente, documentada, auditable y orientada al interés público.

La lectura integral de SUBE Prioridad debe preservar su finalidad social, su neutralidad no partidaria, su atribución de origen, su protección de datos personales, su respeto por derechos vigentes, su rechazo a modelos de vigilancia o sanción y su vocación de evaluación institucional gradual.

SUBE Prioridad no debe interpretarse como una implementación oficial vigente, sino como una base pública para analizar si una arquitectura tecnológica responsable puede contribuir a una experiencia de transporte público más segura, digna y respetuosa.
